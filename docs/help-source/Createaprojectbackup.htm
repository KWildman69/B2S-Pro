Automatic recovery copies

Creating a first B2S backglass ›› More interesting designer stuff ››

B2S Pro automatically writes a separate recovery copy while you work. Its name contains '_AutoRecovery_' and it is stored in the project's 'AutoRecovery' folder.


The recovery copy is a clearly marked '*.B2SPro' file. It never overwrites the finished backglass. A normal Save keeps your changes and removes the temporary copy; choosing 'Don't Save' when closing discards it.


After an unexpected interruption, opening the same backglass offers to restore a newer matching recovery copy. You do not need to create or open a separate project-backup format.
