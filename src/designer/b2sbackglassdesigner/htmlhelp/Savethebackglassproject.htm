Save the backglass project

Creating a first B2S backglass ›› A B2S backglass from scratch ››

There are a few ways to save your backglass project.

  • Click on the 'Save' tool button in the toolbar.
  • Click on the menu item 'File' -> 'Save'.
  • Click on the menu item 'File' -> 'Save all'.



Please notice:

All project data and images are stored together in one '*.B2SPro' file inside the matching project folder. Changes made in the Designer do not alter the original source images.

Saving also updates the recent backglass list and the matching test copy when that option is enabled. An imported legacy '*.directB2S' file is never renamed or overwritten.


Use 'Save copy as ...' when you want a separately named B2S Pro file. Automatic recovery uses a clearly marked temporary '*.B2SPro' copy and never overwrites the finished file.
