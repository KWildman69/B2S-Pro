September 15, 2026 - Final editor and runtime integration
-----------------------------------------------------------

- Added direct, draggable pivot, snippet-reference, launcher, and switch-zone
  handles. Pivot hinges can sit outside the snippet bounds, and switch zones
  retain their authored rotation while triggering from every crossing direction.

August 30, 2026 - Replenishing trough feeder ball
-------------------------------------------------

- Corrected ordered trough motion-path sequences so the ball at the authored
  entry start behaves as a replenishing feeder instead of a permanently painted
  duplicate or a one-time moving member.
- A launch now consumes the visible feeder ball. The feeder respawns when the
  moving member completes the first authored path segment, while that member
  continues along the remaining entry path.

  may launch as soon as the feeder has respawned, and an early repeated trigger
  waits in the existing bounded queue until that feeder is ready.

  Exit/removal and compaction remain serialized until active entries finish, so
  occupancy, survivor order, and slot normalization remain deterministic.
- Added the feeder lifecycle to both backglass and DMD drawing paths. The source
  artwork and final screen-scaled source rectangle still come from the lowest
  ordered member of each named sequence group.
- This is inferred from existing MotionPathSequenceGroup and path-point metadata,
  so existing authored trough files receive the correction without an XML,
  editor-format, trigger-ID, or timing-setting change. Standalone motion paths
  and legacy backglasses remain unchanged.

August 30, 2026 - Complete current server change inventory
-----------------------------------------------------------------------

This section consolidates every custom server-side feature present in the
current 3.0.0 source and runtime. It fills the documentation gap between
the earlier native-rotation work and the completed Motion Path, Pivot, Trough,
and Physics implementation. This is a changelog update only; no runtime logic
was changed while preparing this inventory.

DirectB2S loading and compatibility
-----------------------------------

- Added opt-in parsing for the new native-rotation, motion-path, external-grid,
  pivot, physics-ball, boundary, bumper, switch-zone, and launcher attributes.
- New behavior is registered only when its matching attributes are present.
  Older DirectB2S files without those attributes continue through the existing
  legacy illumination, animation, reel, and rotating-image paths.
- Retained both server forms: the COM DLL receives VPX/ROM commands and the EXE
  owns the displayed backglass. Named-pipe bridges carry only the new physics
  switch pulses and launcher triggers that must cross that process boundary.

Native one-image rotation and mechanical wheels
------------------------------------------------

- Added continuous and command-triggered rotation from one source image with
  configurable direction, step count, interval, and stop behavior.
- Native rotation advances from elapsed time, so dropped Windows timer ticks or
  expensive large-image drawing do not reduce the authored angular speed.
- Large-image caches are prepared independently and all continuous rotations
  remain on their source frame until every required cache is ready.
- Added lamp, solenoid, GI, and B2S-set routing directly to each native rotating
  picture without entering the global legacy rotation timer.
- Added absolute mechanical-position rendering. VPinMAME's 0-359 degree value
  is applied directly, with the configured half-step pointer alignment.
- Preserved generated-frame self rotation and indexed mechanical frame caches
  for legacy files that do not contain enabled native metadata.
- Added transformed backglass and DMD drawing, behind-canvas composition, and
  repaint caching without rotating the surrounding mask or canvas.

Motion paths and trigger routing
--------------------------------

- Added runtime movement along authored multi-point entry and exit paths with
  independent travel durations, looping, pause, resume, and exact saved center
  positions.
- Paths with no start trigger begin automatically. Authored paths can otherwise
  start from a ROM solenoid, ROM lamp, or B2S ID rising edge.
- Exit/removal paths can be triggered independently by a solenoid, lamp, or B2S
  ID. Dedicated B2S IDs can stop and resume an active path.
- Added trigger routing in both the EXE polling path and the public Server COM
  path, so ROM-controlled and EM/B2S-scripted tables use the same animation.
- Repeated triggers can restart the active member or enter a bounded FIFO queue,
  according to the authored Queue Repeated Triggers option.
- Motion interpolation uses elapsed time and the authored coordinate scale;
  start, exit, compaction, and external shifts do not depend on frame count.

Ordered trough and multi-object sequences
-----------------------------------------

- Added named sequence groups and numeric member order so multiple copies of a
  single ball image form independent troughs or other ordered object sets.
- Entry fills the first unoccupied member. Removal always takes the first
  occupied member, plays its exit path, hides it, and shifts every survivor into
  the exact preceding occupied slot.
- Completed compaction normalizes all member centers and cancels old shift
  timers before a freed member can be reused. This prevents overlap, stale
  completion events, and later balls launching from an earlier origin.
- Full, empty, mixed add/remove, queued, and slot-reuse states are guarded. Each
  named group owns its own occupancy and operation queue.

External position grids and pivots
----------------------------------

- Added group-name controlled position grids. One visible representative image
  moves smoothly among authored target positions while the target images remain
  hidden runtime markers.
- Added group-name controlled pivot targets and direct single-image pivot
  animation. A visible representative rotates among authored target angles.
- Added hinge and tip coordinates, down/up angles, duration, and trigger routing
  for solenoid, lamp, and B2S IDs. ON and OFF values drive opposite pivot states.
- Pivot artwork is rendered around the authored hinge using transformed
  destination points and expanded paint bounds, preventing clipping, in/out
  distortion, cumulative bounding-box growth, and stale erased pixels.

Single-ball backglass physics
-----------------------------

- Added elapsed-time ball simulation with substeps, authored gravity, runtime
  coordinate scaling, play bounds, air drag, and configurable common boundary
  bounce.
- Added exact collision against the visible pivot flipper segment from hinge to
  tip. Flipper angular velocity and authored strength are transferred to the
  ball only when the rendered flipper physically contacts it.
- Added any number of independent polyline boundaries. Every finite segment and
  rounded end cap collides from either side, regardless of point-drawing order;
  distant segments cannot attract or launch the ball.
- Added circular bumper/obstacle collision using each authored visible radius.
- Added rectangular switch zones that pulse the configured ROM switch once when
  the ball enters, reset after it leaves, and can score through VPX/VPinMAME.
- Added one authored launcher for the physics ball with origin, direction,
  strength, random-angle range, random-strength range, and capture radius.
- Launcher triggers support ROM solenoid and B2S ID input. Repeated pulses are
  ignored while the ball is in flight; after the ball leaves and later returns
  to the capture area, it is held, rearmed, and ready for another full cycle.
- Added DLL-to-EXE launcher delivery and EXE-to-DLL switch-pulse delivery so the
  process that receives VPX commands and the process that owns the physics ball
  remain synchronized.

Rendering, animation, and score-display corrections retained
--------------------------------------------------------------

- Retained transparent-image visible-bounds cropping and targeted parent
  invalidation for faster large illumination animations.
- Retained the continuous-animation loop-seam correction and stable Dream7 score
  display ordering during full-screen redraws.
- Retained rotating snippets and live EM reels behind the canvas, including
  rolling and illuminated reel states.

  runtime scaling. Large square artwork therefore rotates around its true
  center without the elliptical or off-center distortion caused by scaling the
  source first.
- Multiple continuous one-image rotations prepare independent caches and begin
  together only after every continuous cache is ready. Their stationary source
  images remain visible during preparation instead of leaving blank areas.
- Smooth spin-off now continues from the actual current angle and decelerates

- B2S Pro continues to expose Self Rotating Image when editing an existing

- Runtime and editor tests passed for continuous rotation, lamp and solenoid
  triggers, all stopping modes, multiple simultaneous images, large images,
  legacy loading and round-trip saving, and absolute-position mechanical
  wheels stopping on the correct value.
